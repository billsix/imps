=========================================
Appendix E: The reference set
=========================================

This book is the guided tour. Behind it sits an exhaustive, per-topic reference
set — the notes each chapter's "Go deeper" box points at — in the imps
repository at ``tasks/reference/mario64/``. Each topic there is written at
several **levels of detail**: a one-paragraph capsule in the ``README.md`` map, a
one-page mental model where the idea is subtle, and a full mechanism note with
every ``file:line`` anchor. Start at that ``README.md`` for the map; drop into a
topic note when this book's chapter leaves you wanting the whole thing.

The set covers, in depth: vectors and matrices, transforms, rotation, the camera
system, projection, the graphics pipeline, the color combiner and generated
shaders, textures, sampling and HD assets, lighting, transparency, skyboxes,
water, the wobbling paintings, collision, animation, the scene graph, sound,
frame interpolation, and a note on what is deliberately absent (there is no ray
tracer, and no implicit-surface modeling).

## Shape

Static lib, `PREFIX ""`, C++20 + C11, `file(GLOB)`; no
install/export/VERSION; `ENABLE_EXPORTS` + `WINDOWS_EXPORT_ALL_SYMBOLS`
(`src/CMakeLists.txt:8-9`); `enable_testing()` behind `LUS_BUILD_TESTS`
(OFF, `CMakeLists.txt:84-87`; same 16-file gtest suite as mainline —
the fork touched none of it). **Python is GONE**: zero
`find_package(Python3)`; `DefaultKeys.h` is generated by a **C++17 host
tool** `tools/generate_keys_header.cpp` compiled at build time
(cross-compile-aware bootstrap, `src/CMakeLists.txt:23-71`); no
pip/python steps in any workflow. Vestigial: `requirements.txt` +
`tools/generate_keys.py`/`sign.py` still ship for offline archive
signing only.

## Options

`NON_PORTABLE` / `DISABLE_DLL_LOADER` / `ENABLE_SCRIPTING` (**still
default OFF even on this scripting fork** — CI's tidy workflow enables
it explicitly) / `INCLUDE_MPQ_SUPPORT` (OFF) / `GBI_UCODE` /
`LUS_BUILD_TESTS` (OFF) — all as mainline 463 (`CMakeLists.txt:10-12,
41-42,84`); NEW iOS-only `SIGN_LIBRARY`/`BUNDLE_ID` (`:15-16`).
**Vulkan is auto-detected, not an option**: `find_package(Vulkan
QUIET)` on every platform except iOS/Android sets internal
`LUS_ENABLE_VULKAN` (`cmake/dependencies/common.cmake:42-145`, incl. a
Windows VulkanSDK auto-glob and a shaderc_shared/combined + glslang
link dance) → `ENABLE_VULKAN` compile def PUBLIC + `Vulkan::Vulkan` +
shaderc (`src/CMakeLists.txt:171-177`). A `cmake/FindVulkan.cmake`
override ships.

`cmake/cvars.cmake` has **23** macros (byte-identical to mainline 486 —
the earlier iterations' "24" was a miscount), including
`CVAR_ALLOW_BACKGROUND_INPUTS` (used) and `CVAR_SCRIPT_SAFE_LEVEL`
(still zero references). The fork's shader settings use a *dynamic*
CVar namespace instead (`config-cvars-logging.md`).

## Dependencies — fork deltas

- **TinyCC**: still `GIT_TAG mob` (moving branch) but repo switched to
  **`Net64DD/tinycc`** (`common.cmake:266-268`); configure-time
  `execute_process(./configure)` remains; NEW portability layer —
  `CONFIG_TCC_CRTPREFIX` rewritten to try a bundled `{B}/lib` first
  (`:298-327`), iOS codesign disabled, MSVC builds tcc from source. NEW
  **`cmake/SetupTccRuntime.cmake`** (161 lines): exported
  `lus_setup_tcc_runtime(TARGET …)` stages `.tcc/include` + `.tcc/lib`
  next to the consumer binary — this is what Ghostship's `.tcc` dir is.
- **prism**: `KiritoDv/prism-processor` @ `aa837098` — different repo
  AND SHA vs mainline 486's `1de05445` (`common.cmake:217-218`).
- **monocypher**: unchanged (unconditional, PUBLIC, SHA `0d85f98c`).
- **Vulkan + shaderc** (above); ImGui gains `imgui_impl_vulkan.cpp`
  (`common.cmake:62-63`).
- Everything else as 463/486: ImGui `v1.91.9b-docking`+patch, StormLib
  v9.25 (MPQ-gated), stb `file(DOWNLOAD)`, thread-pool v4.1.0,
  googletest v1.16.0, spdlog mac v1.16.0, SDL2 2.32.10 fallbacks
  android/iOS only, **Linux still no FetchContent fallback**.

## Platform matrix

Windows / Darwin / iOS / Linux / Android / OpenBSD (cmake dispatch,
`CMakeLists.txt:45-74`). **Web/emscripten is code-level only** — no
cmake dispatch; `__EMSCRIPTEN__` guards in `gfx_sdl2.cpp:43-46,
414-423`, `gfx_opengl.cpp`, `interpreter.cpp`, and the `"/storage"`
app dir (`Context.cpp:528-530`). HEAD commit = GLES3 fixes (ES3
context attributes under `USE_OPENGLES`; `GL_MIRROR_CLAMP_TO_EDGE` →
`GL_MIRRORED_REPEAT` for ES3/WebGL2). `ENABLE_DX12` still only dead
guards; Switch/WiiU absent.

## CI

`build-validation.yml`: mac/iOS (macos-14), Linux + Android
(ubuntu-latest), windows x64 + arm64 both **`windows-latest`** (the
mainline #1130 windows-2022 arm64 pin is absent). `apt-deps.txt` adds
**`libvulkan-dev libshaderc-dev`** alongside `tcc libtcc-dev`; zero
pip. `test-validation.yml` + tidy workflows as at 463 (tidy enables
`ENABLE_SCRIPTING`). Artifacts still `soh-*`; Linux CI still
hand-builds SDL2 2.24.1.

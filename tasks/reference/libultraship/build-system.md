## Shape

Root `CMakeLists.txt` (min cmake **3.24**): platform prologue, optional
vcpkg automation (Windows), then per-OS dependency files and
`add_subdirectory(src)`. **`extern/` no longer exists** — the −529k
line delta vs 1.4.2 is the vendored trees leaving. Product is still one
static library, `PREFIX ""` → `libultraship.a`, now **C++20 + C11**
(C11 for libgfxd's `_Alignas`; `src/CMakeLists.txt:3-7`). Still **no
`install()`/`export()`/tests**; `project()` still has no VERSION and no
version constant exists in code. Sources are still `file(GLOB)` — a new
`.cpp` needs a CMake re-run.

## Dependencies — FetchContent + find_package (no submodules, no vendoring)

Dispatch: `cmake/dependencies/windows-vcpkg.cmake` (if `USE_AUTO_VCPKG`)
→ **`common.cmake` unconditionally** → one per-OS file
(`CMakeLists.txt:30-55`).

| Dep | Pin | Mechanism (all paths under `cmake/dependencies/`) |
|---|---|---|
| ImGui | `v1.91.9b-docking` | FetchContent + local patch `patches/imgui-fixes-and-config.patch`, hand-rolled `add_library(ImGui STATIC)` — `common.cmake:9-36` |
| StormLib | `v9.25` + optimizations patch | FetchContent, **only if `INCLUDE_MPQ_SUPPORT`** — `common.cmake:39-51` |
| stb_image | SHA `0bc88af4` | `file(DOWNLOAD)` of the single header; `stb_impl.c` generated by `file(WRITE)` at configure — `common.cmake:53-66` |
| libgfxd | SHA `008f73dc` | FetchContent, only if `GFX_DEBUG_DISASSEMBLER` — `common.cmake:68-94` |
| BS::thread-pool | `v4.1.0` | FetchContent, include-dir only (never linked) — `common.cmake:96-104` |
| prism-processor | SHA `bbcbc7e3` (KiritoDv) | FetchContent, linked **PUBLIC** — `common.cmake:106-113`; the runtime shader templater (`fast3d-renderer.md`) |
| SDL2 | `release-2.32.10` | `find_package` QUIET → FetchContent fallback **android/iOS only** |
| nlohmann_json / tinyxml2 / libzip | `v3.12.0` / `11.0.0` / `v1.11.4` | same android/iOS-only fallback pattern |
| spdlog | `v1.16.0` (android/iOS), `v1.14.1` (mac) | FetchContent fallback |
| metal-cpp | tag `macOS13_iOS16` | FetchContent (briaguya single-header) — `mac.cmake:18-24` |
| GLEW / OpenGL | system | `find_package` (GLEW mac+windows only) |

**Linux has NO fallback**: `linux.cmake` is 10 lines
(`find_package(SDL2 REQUIRED)` + ImGui link). json/tinyxml2/spdlog/
libzip come from bare `find_package(... REQUIRED)` in
`src/CMakeLists.txt:66-76` — a missing distro `-dev` package is a hard
configure failure. Only android/iOS get the FetchContent safety net.
**libzip is the one new system dep** (`.o2r` = zip); it links PRIVATE
but the public `O2rArchive.h:9` includes `zip.h`, so consumers still
need its headers.

Gone vs 1.4.2: ZAPDUtils (FileHelper/PathHelper absorbed into
`include/ship/utils/filesystemtools/`), StrHash64-as-target (now
`src/ship/utils/StrHash64.cpp`), dr_libs (deleted — the "unused dep"
resolved by removal), the vendored `dxsdk/` D3D12 headers, PulseAudio,
X11/GLX. New: libzip, prism, libgfxd, `glob.c` vendored from the Linux
kernel (`src/ship/utils/glob.c`).

## Options / feature flags

| Option | Default | Notes |
|---|---|---|
| `INCLUDE_MPQ_SUPPORT` | **OFF** (`CMakeLists.txt:27`) | opt-IN (name inverted from later lines' `EXCLUDE_`); default build has no StormLib and **cannot open `.otr`** |
| `NON_PORTABLE` | OFF | → generated `install_config.h`, app-dir model (`Context.cpp:407,487`) |
| `GBI_UCODE` | `F3DEX_GBI_2` | applied **PRIVATE** (`src/CMakeLists.txt:111`) but it changes public `gbi.h` struct/macro layout — a consumer that doesn't define it too compiles a different GBI ABI than the library. Only `.cpp` consumer: `GfxDebuggerWindow.cpp` |
| `USE_OPENGLES` / `GFX_DEBUG_DISASSEMBLER` | OFF | `src/CMakeLists.txt:10-11` |
| `SPDLOG_MIN_CUTOFF` | `SPDLOG_LEVEL_TRACE` | validated cache STRING (`src/CMakeLists.txt:137-141`) |
| `USE_AUTO_VCPKG` | still never `option()`-declared | `windows-vcpkg.cmake:1`; vcpkg still `git pull`s unpinned; port list now `zlib bzip2 sdl2 glew libzip nlohmann-json tinyxml2 spdlog` |

**NEW: `cmake/cvars.cmake`** — 22 `CVAR_*` cache strings pushed as
global `add_compile_definitions` string macros (included at
`src/CMakeLists.txt:1`), letting a port **rename LUS's own CVar keys at
build time**. See `config-cvars-logging.md`.

## Platform matrix

Windows, Darwin, iOS, Linux, Android. **Switch and Wii U/CafeOS are
deleted** (zero grep hits); `src/port/` shrank to
`src/ship/port/mobile/MobileImpl.cpp` (android/iOS,
`src/ship/CMakeLists.txt:75-79`). Compile defs: Windows `ENABLE_DX11
NOMINMAX …` (`src/CMakeLists.txt:113-121`); iOS `__IOS__`, **no
`ENABLE_OPENGL`** (`:143-149`); everyone else `ENABLE_OPENGL`
(`:172-179`). `ENABLE_DX12` survives only as a never-defined macro in 7
dead guards — the D3D12/GLX source files are gone entirely.

Link visibility (`src/CMakeLists.txt`): PUBLIC ImGui, nlohmann_json,
tinyxml2, spdlog, prism, storm-when-MPQ (whole-archive off
Windows/iOS); PRIVATE stb, libgfxd, libzip, Threads + Apple frameworks.

## Known quirks at this pin

- Fast3D backend exclusion filters are dead: `src/fast/CMakeLists.txt:26`
  globs `backends/*.cpp` but the `EXCLUDE REGEX` (`:29-40`) still
  matches the pre-move `graphic/Fast3D/backends/` prefix — nothing is
  ever filtered; only per-file `#ifdef`s save it.
- `.mm` files still compiled `-fno-objc-arc` against global ARC — now
  two (`AppleFolderManager.mm`, `macUtils.mm`, `src/CMakeLists.txt:32-38`).
- CI (`.github/workflows/build-validation.yml`): macos-14, iOS,
  ubuntu-latest, Android NDK, windows x64+arm64; artifacts **still
  named `soh-*`**; Linux CI still hand-builds SDL2 **2.24.1** despite
  the 2.32.10 pin elsewhere. Deps files `apt-deps.txt`/`brew-deps.txt`
  exist at repo root of `.github/workflows/`.
- `${Source_Files__Log__SPDLog}` dangling-variable quirk: resolved (the
  CMake files were rewritten).
